This research presents an adaptive malware detection system for cloud-native CI/CD pipelines that continuously evolves through self-learning, real and adversarially mutated threat training, and real-time code and behavior analysis. By embedding the detector directly in the pipeline and automating both benign promotion and self-healing remediation for suspicious changes, the approach achieves frictionless yet robust security, substantially outperforming traditional SAST and DAST in accuracy, adaptability, and efficiency. The system’s continuous feedback loop, incorporating real operational and synthetic threats, ensures resilience against newly emerging malware, optimizes detection accuracy, and maintains pipeline throughput, making it a practical and scalable solution for modern cloud DevOps workflows in dynamic, high-speed deployment environments.
